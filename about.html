About This Project

This project is an interactive 3D web application developed using HTML5, CSS3, JavaScript and Three.js.

3D Modelling Workflow

The 3D controller models were created and exported from Blender using the glTF (.glb) format.

Technologies Used

  • HTML5
  • CSS3
  • JavaScript
  • Three.js
  • Blender

Accessibility

High contrast colours, responsive layouts and interactive buttons were used to improve accessibility and usability.

Testing

The application was tested in modern desktop browsers to ensure responsive behaviour and correct 3D rendering.

Deeper Understanding Features

  • Dynamic 3D model loading
  • Wireframe rendering mode
  • Interactive lighting controls
  • JavaScript animation system
  • MVC-inspired architecture
