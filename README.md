# GAME TECH – Interactive 3D Controller Showcase

## Project Overview

GAME TECH is an interactive Web 3D application developed using HTML5, CSS3, JavaScript and Three.js. The application showcases multiple 3D gaming controller models created in Blender and exported as GLB files for real-time rendering in the browser.

The project was developed as part of the 3D Apps module assignment and demonstrates responsive web design, 3D model integration, interactive controls, lighting systems and WebGL rendering using Three.js.

---

## Features

- Interactive 3D controller showcase
- Real-time GLB model loading
- Orbit camera controls
- Wireframe rendering mode
- Lighting toggle system
- Rotation animation controls
- Responsive web layout
- CSS-styled logo and interface
- Multiple 3D controller models
- About page with development documentation
